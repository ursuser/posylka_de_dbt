## Server maintenance — 2026-03-31

**What was done:**
- Investigated high CPU on Dagster daemon (~100% constantly, even with no active runs)
- Root cause: daemon uses `python_module` approach — spawns gRPC code location processes every 30 seconds to check schedules/sensors, processes die after 20s idle, daemon respawns them — infinite loop
- Discovered `fittra_uk` was registered in `workspace.yaml` but had no active schedules (all disabled in Dagster UI)
- Removed `fittra_uk` from `/root/orchestration/workspace.yaml`
- Restarted webserver + daemon containers
- Result: CPU dropped from ~100% to ~1%, RAM dropped from ~1.3GB to ~560MB

**Checked 2026-04-01:** daemon CPU 0.9%, RAM 296 MB — fix confirmed, no further action needed.
